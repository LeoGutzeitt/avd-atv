## 🤖 Transparência sobre o uso de IA

Sim, usei IA ([Gemini / ChatGPT]) neste projeto. 

A IA funcionou como estagiária sênior: ela escreveu muito do código braçal, corrigiu meus erros de digitação e me poupou de surtar com a documentação do Streamlit às 2 da manhã. 

Meu papel foi o de arquiteto: eu tive as ideias, formulei as perguntas, mandei ela refazer quando veio porcaria e testei tudo até rodar liso. O código é dela em parte, mas a responsabilidade (e a nota) é toda minha.


"O prompt foi minha ferramenta de engenharia: usei a IA como se fosse um colega de equipe sênior que digita rápido, mas que precisa que eu dê as regras do jogo, o contexto dos dados e valide se o resultado não é pura alucinação."
